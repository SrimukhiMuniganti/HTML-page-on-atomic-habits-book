# HTML Page on Atomic Habits

This project is a simple HTML webpage created to give a brief overview of the book **Atomic Habits** by James Clear.

## 📖 About the Project

The webpage presents information about the book **Atomic Habits** and its key ideas in a simple and visually appealing way.

This is one of my beginner web development projects created using HTML.

## 🛠️ Technologies Used

- HTML
- Images
- Audio
- Basic web page design

## 📚 About Atomic Habits

**Atomic Habits** is a book by **James Clear** that explains how small, consistent changes can help build good habits and reduce bad ones.

The main idea is that small improvements made consistently can lead to significant results over time.

## 🎯 Purpose

The purpose of this project is to:

- Practice HTML
- Learn how to add images to a webpage
- Learn how to add audio to a webpage
- Understand basic webpage structure
- Create a simple webpage based on a real-world topic

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `project.html` in a web browser.
4. Make sure the image and audio files remain in the same folder so that all content works correctly.
